# Hardware Specification

This document lists the currently specified hardware components for the AI Glasses project.

## Components
- **Microcontroller**: Seeed Studio XIAO ESP32-S3 Sense
- **Camera Module**: OV3660
- **Audio**: Audio hardware (I2S Microphone / Speaker / Amplifier - specific components pending verification)
- **IMU**: MPU6050 (6-axis accelerometer and gyroscope)
- **Input**: Capacitive touch sensor
- **Power**: LiPo battery
- **Storage**: MicroSD card reader (integrated/external)
